# M3 v2 verification and closure

Status: Accepted historical record  
Date: 2026-07-10

## Delivered

- process, services/cgroups, network, timers/mounts, and event views;
- current sort/filter/tree/search state displayed in every view;
- free-text process/executable, socket, and mount search;
- parent-first depth-first process ordering with bounded cycle handling;
- exact details, self marker, typed coverage failures, socket owners, and collector loss state;
- optional finite kernel-event timeline through `--tui --events N`;
- cached broad inventory with explicit `r` refresh, preventing systemd queries every frame;
- schema-v3 snapshot and schema-v1 inventory/event exports;
- catchable SIGHUP/SIGINT/SIGTERM shutdown through the terminal restoration guard.

## Verification

- Sixteen release tests, formatting, warnings-as-errors Clippy, and release build pass.
- Snapshot-history and complete-inventory JSON parse as valid documents.
- A pseudo-terminal exercise verified search, tree toggle, all five views, event-disabled coverage, and `q` restoration.
- A separate pseudo-terminal run received SIGTERM; its transcript contained the cursor and alternate-screen restoration sequence before exit.
- Non-terminal TUI invocation remains an explicit error.

## Hard boundary

SIGKILL cannot be handled. The TUI depends on Arch’s `stty`; snapshot, event, inventory, and JSON modes do not. Event display appears as the finite collector returns rather than as an unbounded daemon stream.

M3 v2 is complete against its accepted gates.
