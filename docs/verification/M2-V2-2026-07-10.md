# M2 v2 verification and closure

Status: Accepted historical record  
Date: 2026-07-10  
Reference: Arch Linux 7.1.3, Hyprland/Wayland

## Delivered

- complete system/user running-unit and timer queries with typed unsupported/error states;
- cgroup-v2 count and hierarchy; process cgroup/unit association;
- TCP/UDP/Unix socket inventories with inode-to-visible-PID ownership evidence;
- current mount inventory and per-process PID/mount/network/user/cgroup namespace identities;
- explicit unknown ownership when file-descriptor or namespace evidence is unavailable;
- optional process-event recording, off by default, `0600`, command-free, and hard byte-capped;
- versioned JSON for snapshots, events, and full background inventory.

## Real-host evidence

Read-only Arch/Hyprland inventory observed 354 processes, 962 threads, 46 associated units, 26 running system units, 24 running user units, 713 sockets, 81 cgroups, 28 mounts, 4 system timers, and no user timers. Multiple listener inodes were mapped to visible owner PIDs; other listeners remained `owners: []` rather than guessed.

A live elevated recording captured one kernel event into a 254-byte file under a 512-byte cap. Mode was exactly `0600` and the header stated `commands_included:false`.

Twenty real-host reconciliation snapshots across roughly 352 processes averaged 18.262 ms, minimum 13.482 ms, maximum 21.025 ms, with zero enumeration errors. The existing synthetic 2,000-process fixture remains below its 250 ms assertion.

## Boundaries

Socket ownership is evidence from visible `/proc/PID/fd`, not proof of exclusive ownership. Inventories describe the current namespaces. systemd may be absent/unreachable. Application-internal and arbitrary kernel timers are not enumerable through the systemd timer source.

M2 v2 is complete against its accepted gates.
