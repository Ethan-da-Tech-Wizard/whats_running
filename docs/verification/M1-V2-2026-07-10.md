# M1 v2 verification and closure

Status: Accepted historical record  
Date: 2026-07-10  
Environment: Arch Linux 7.1.3-arch1-1, Hyprland/Wayland, Rust 1.96.0

## Delivered

- command files are unopened and represented `not_collected` unless explicitly requested;
- typed availability for identity, numeric metrics, strings, cgroups, units, and thread inventory;
- Linux CPU totals exclude guest/guest-nice double counting;
- individual threads include TID, name, state, start ticks, and CPU counters;
- processes include cgroup-v2 path and inferred systemd service/scope/slice;
- proc-connector fork/exec/exit stream, explicit permission failure, per-CPU sequence-loss accounting, before/after reconciliation, and observer identity;
- schema-v3 snapshots and schema-v1 JSON lifecycle-event lines.

## Evidence

- Fifteen tests pass with warnings-as-errors Clippy and a release build.
- Live schema-v3 validation reported all default command statuses as `not_collected` and exported individual threads.
- Unprivileged connector subscription failed explicitly with the documented capability message.
- An explicitly approved elevated Arch-kernel validation captured a real exit event, reported `sequence_gaps: 0`, completed reconciliation, and included the observer PID.
- A prior elevated probe exposed acknowledgment filtering and global-sequence bugs; both were corrected before closure. Sequence tracking is per CPU as required by observed connector behavior.

M1 v2 is complete. Socket/timer/mount inventory and recording prototypes already exist but remain M2 work until their full gates pass.
