# M3 closure

Date: 2026-07-10  
Status: Historical record

The interactive Arch/Hyprland terminal view now provides sorting, visible filters, ancestry indentation, selection, details, resizing, self-identification, and ordinary terminal restoration without a Rust dependency or second collector.

The restraint remains deliberate: this is a readable instrument panel, not a neon spaceship. There is no mouse layer, theme engine, compositor API, or background service. M4 can focus on explaining heat and slowness without destabilizing process truth.
