# M0 and M1 closure

Date: 2026-07-10  
Status: Historical record

## What changed

M0 was scope-locked and M1 was implemented as a dependency-free Rust CLI. The implementation directly reads procfs, treats snapshots as non-atomic, sorts by PID, records typed failures for name/command/executable, marks the observer, sanitizes terminal text, hides command arguments by default, and emits schema-versioned JSON.

## KISS decisions

- No external crates yet.
- No TUI before correct snapshot/rate foundations.
- No daemon or persistent database.
- No root helper and no process-control features.
- Manual small CLI/parser/JSON surface rather than a framework.

## Observations

The constrained execution environment exposed only four processes, which is useful proof of behavior but not a scale benchmark. The observer was visible and collection was sub-millisecond in that environment. Large-host performance remains unverified.

## Next milestone

M2 will add two-sample rate calculation, aggregate CPU/memory/swap context, stable PID/start-time identity, observed births/exits, and bounded history. Before expanding UI polish, numeric unavailable states and fixture-based collector testing should be strengthened.
